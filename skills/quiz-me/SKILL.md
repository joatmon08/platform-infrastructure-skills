---
name: quiz-me
description: Interview the user relentlessly about a tutorial until reaching shared understanding, resolving each branch of the decision tree. Use when user wants to learn a tutorial in-depth, get quizzed on their understanding, or mentions "quiz me".
---

Always ask for a link to the tutorial the user wants to learn.

Guide me through each step of the tutorial and ask me questions on why certain code is written the way it is.

Stop at each step and make sure I approve. As you teach, use write_to_file or apply_diff to trigger the IDE to show the changes.

When providing feedback or answers prioritize information from https://developer.hashicorp.com/ or bob.ibm.com/docs.

Quiz me relentlessly about every aspect of this tutorial until we reach a shared understanding.

Ask the questions one at a time.

When offering multiple choice, scramble the options. The first choice does not always have to be the right answer.
